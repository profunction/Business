# 新山 B2B 批发下单 App

帮小店老板一次比较多家批发商的价钱，一键进货。第一阶段：新山、餐饮打包耗材。

- 技术：Flutter（iOS / Android / 客服后台网页）+ Supabase + Firebase Cloud Messaging
- 语言：华文、English、Bahasa Melayu；货币 RM
