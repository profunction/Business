## 2. 几个设计决定

- **价钱刚好改了怎么办**：确认页把老板看到的总额一起送给服务器（`p_expected_total_sen`），对不上就不下单，弹出「价钱改了，请再看一次总额」，画面换成新报价。不会照旧价、也不会偷偷多收。
- **「跟上次一样」是两下**：第一下放回购物车并到确认页，第二下确认。中间这一页不能省，因为要让老板看到总额（第三步的要求），价钱也可能变了。
- **免费版不放「付款」按钮**：第七步才回答「Apple / Google 是否一定要用应用内购买」。在那之前，锁住的价钱旁边只有「把这家加进免费名单」，设定页写「付费订阅很快推出」。
- **订单详情的按钮由服务器决定**：`get_order()` 回传 `actions`（可以取消、可以按收到了、可以评价），规则跟改状态的函数是同一套，App 不会显示按了会失败的按钮。
- **从链接直接打开某一页**（以后通知会用到）：读完登录资料后回到原本的页面，不会被带回首页。

## 4. 代码在哪里

```
packages/core/          共用（客服后台也会用）：数据模型、金额和手机号格式、所有服务器调用（WholesaleApi）
apps/mobile/lib/
  main.dart             正式入口
  main_demo.dart        示范模式入口（不用服务器）
  app/                  设定、主题（大字）、登录状态、页面跳转、三语工具
  l10n/                 三语文字：app_zh.arb / app_en.arb / app_ms.arb（194 条）
  widgets/              共用零件：大按钮、＋／－、状态标签、模糊价钱……
  features/             每一页：auth、onboarding、home、browse、cart、orders、settings
  demo/                 示范模式的假服务器（数据来自真实样本）
```

改字只要改那三个 `.arb` 文件。App 名称先用了「新山批发 / JB Wholesale / Borong JB」，定了正式名字再改 `appTitle`。

## 5. 怎么看、怎么测

见 [`apps/mobile/README.md`](../apps/mobile/README.md)：

- **不用服务器先看画面**：`flutter run -t lib/main_demo.dart -d chrome`
- **连本机 Supabase**（要 Docker）：`npx supabase start` 之后照 README 设定
- **测试**：`./scripts/test-db.sh`（数据库）、`cd packages/core && dart test`、`cd apps/mobile && flutter test`

App 的测试用示范模式把整个 App 点一遍：选语言、登录、开店、跟上次一样、价钱改了、比价、模糊价钱和解锁、放进购物车、购物车问题、订单状态和收到了、评价、换语言。手机宽度设成 400，大字把画面撑爆会直接失败（已经抓到并修好一处：购物车的金额在窄手机上放不下）。
