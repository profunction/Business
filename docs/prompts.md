# 开发提示词（最新版）

一次贴一段给 Claude，测试没问题再贴下一段。第一步和第七步已按最后定的收费方式修改。

---

## 第一步：总体说明（第一次对话先贴这段）

```
我要做一个马来西亚 B2B 批发下单 App，帮小店老板一次比较多家批发商的价钱，一键进货。

三种用户：
- 买家：小店老板（餐馆、饮料店、杂货店）
- 卖家：批发商
- 管理员：我们的客服，可以代任何人操作

业务规则：
- 我们不碰物流，批发商自己送货，运费由买家付，下单时就显示
- 很多老板和批发商不太会用手机，界面要比 WhatsApp 还简单（大字、少按钮）
- 不会用 App 的人可以用 WhatsApp 下单和接单，由客服在后台转成订单
- 第一阶段只做一个地区（新山）、一个行业（餐饮打包耗材）

技术：用 Flutter 做手机 App（iOS 和 Android），Supabase 做后端（数据库、登录、存储），Firebase Cloud Messaging 做推送通知。界面支持中文、英文、马来文，货币用令吉（RM）。

请先给我整体架构、数据库表设计和开发步骤，不要一次写完所有代码。之后我会一步一步请你做。
```

## 第二步：数据库

```
请设计 Supabase 数据库，包括：
- 用户（角色：买家 / 卖家 / 管理员）
- 店铺（买家的店）、批发商
- 商品：名称、照片、单位、价钱、起订量、库存状态、送货地区、送货时间
- 订单、订单明细、运费
- 评价和评分
- 订阅：开始日期、月费金额、是否锁定「创始价」
- 抽佣记录：每张订单的佣金比例和金额
- 批发商的佣金比例（按行业设定，可以单独调整，创始会员比较低）

加上行级安全规则（RLS）：买家只看到自己的订单，批发商只看到给他们的订单，管理员看到全部。
```

## 第三步：买家功能

```
请做买家端：
- 浏览批发商和商品；同一样商品可以比较多家，除了价钱也显示评分、送货时间和起订量
- 购物车和下单，下单前显示货价加运费的总额
- 首页放一个大按钮「跟上次一样」，一键重复下单
- 订单状态追踪（已确认 / 缺货 / 送货中 / 已送达）
- 给批发商评分和评价
- 大字、简单的界面，每页只做一件事
- 未付费用户只能完整看到三家批发商，其他批发商的价钱模糊显示
```

## 第四步：批发商功能

```
请做批发商端：
- 新订单推送通知，一键「确认」或「缺货」
- 每天早上一份当天订单总结，可以打印给送货员
- 上传价钱表照片或 Excel，由 AI 转成商品目录，确认后才上架
- 修改价钱和库存
- 没装 App 的批发商：订单用 WhatsApp Business API 模板消息发给他，消息里有「确认」和「缺货」按钮
```

## 第五步：客服后台

```
请做网页版管理后台：
- 代任何买家下单
- 代批发商上架、改价钱、改库存
- 查看所有订单和状态
- 管理订阅（包括创始价账号）
- 每月抽佣报表：每家批发商这个月的订单总额和应付佣金，可以导出成账单
```

## 第六步：语音和 WhatsApp 下单

```
请加入语音下单：用户按住按钮，用华语、广东话、福建话、马来文或英文说出要买的东西，AI 转成订单草稿，用户确认后才送出。

另外设计 WhatsApp 下单流程：老板发文字或语音到我们的 WhatsApp 号码，系统转成订单草稿，由客服在后台确认后送出。

WhatsApp 按条收费，所以平时的通知全部用推送，WhatsApp 只给没装 App 的人用。
```

## 第七步：收费

```
请加入收费功能：
- 买家月费 RM50，所有功能都能用。注册时的价钱跟着账号锁定，只要一直续费就永远是这个价；中途停了再回来，就付当时的新价钱
- 新买家 14 天免费试用
- 批发商按订单抽佣，比例按行业设定（1% 到 3%），创始会员比较低
- 头 100 家批发商付 RM100 创始会员上架费
- 前期佣金用月底账单收：系统每个月自动算好每家批发商的佣金，生成账单
- 付款接马来西亚的付款网关，支持 FPX 网银、DuitNow 和电子钱包

另外请告诉我：按照 Apple 和 Google 的规定，买家的月费一定要用应用内购买吗？还是可以用网页付款？
```

## 第八步：公司采购（像大公司用的采购平台）

```
小店照旧。另外加「公司账号」给公司、工厂、酒店、连锁餐厅、GLC：一家公司有很多员工、很多分店，有角色（申请人 / 审批人 / 财务 / 管理员）和预算。

请做：
- 采购流程：员工开申请单 → 按金额、分类、分店的规则多层审批（系统自动提醒：拆单避开审批、价钱比市场高、数量不正常）→ 变成给批发商的采购单 → 到货开收货单（可以部分收货）→ 采购单、收货单、发票三方对账 → 月结单和赊账期
- 询价和竞价：没上架的货或大量的货，邀请几家批发商报价（App 里报，或用 WhatsApp / 上传报价单，由 AI 整理成同一个格式），并排比较、还价、限时反向竞价，选中的变成采购单
- 比价：同一样或差不多的商品跨批发商比较（AI 对商品），告诉老板「这个价钱合不合理」
- 开支分析：按公司、分店、分类、批发商看花了多少钱，同一样东西买贵了的、可以合并采购省钱的，AI 写一段总结
- 公开网站：介绍、怎么用、不用登录就能看商品分类、常见问题、注册公司或小店、申请成为批发商（客服在后台审核）
- 公司方案怎么收费，手机 App 要注意什么

功能可以参考别人的采购平台，但名字、文字、样子都要自己的。先写设计，分几期做，每期能自己测试。
```
